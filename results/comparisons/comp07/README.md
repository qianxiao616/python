Contents of this folder:

- `run_compare_comp07.py`: convenience script to (re)generate comparison CSV and PNG for `comp07`.
- `compare_comp07.png`: model comparison visualization (bar cost + satisfaction line).
- `compare_comp07.csv`: summary CSV with per-model metrics and satisfaction scores.

Guidance:

- To regenerate results, from repository root run:

```bash
python results/comparisons/comp07/run_compare_comp07.py
```

- This folder collects all artifacts related to model comparison for `comp07`.
